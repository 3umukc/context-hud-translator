# Context HUD Translator (Windows)

Высокопроизводительное десктопное приложение для Windows, выполняющее синхронный перевод текста без потери контекста, смысловых сдвигов и искажений многозначных слов (WSD — Word-Sense Disambiguation).

Позволяет вводить текст на родном языке в любом приложении (браузер, чаты, мессенджеры, текстовые редакторы, игры в оконном режиме), при этом текст прямо в поле ввода мгновенно заменяется на грамматически согласованный перевод.

---

## Архитектура и возможности

### 1. Прямой ввод в активное поле (Live In-Place Replacement)
* Вы печатаете в любом поле ввода стороннего приложения. При нажатии пробела или знака препинания введенные слова прямо на месте заменяются на перевод.
* Никаких всплывающих окон и необходимости ручного копирования или вставки.
* Скорость подстановки оптимизирована до 1.5 мс через внутреннюю очередь с буфером обмена Windows, что исключает коллизии символов при высокой скорости слепой печати.
* Переключение режима в реальном времени: комбинация клавиш `Alt + T` или меню системного трея.

### 2. Динамическое контекстное окно предложения (Sliding Sentence Context Window)
* Устранена проблема изолированного пословного перевода (когда глаголы третьего лица переводятся с ложными местоимениями вроде "he").
* Система ведет цепочку слов текущей фразы. При добавлении каждого нового слова предложение согласуется целиком (число, залог, падеж).
* При завершении предложения знаками препинания (`.`, `!`, `?`, `,`) или клавишей Enter фраза фиксируется, и контекст безопасно сбрасывается для следующего предложения.

### 3. Автоматический сброс контекста при редактировании
* Буфер контекста автоматически сбрасывается при операциях редактирования: `Ctrl + A` (выделение всего текста), `Ctrl + X` (вырезать), `Ctrl + Z` (отмена), `Ctrl + Y` (повтор), `Ctrl + V` (вставка), `Ctrl + Backspace`, `Ctrl + Delete`.
* При нажатии `Backspace` за пределами текущего слова (удаление пробела или возврат к предыдущим словам) контекст сбрасывается, предотвращая появление фрагментов старых фраз.
* Глобальный низкоуровневый хук мыши (`WH_MOUSE_LL`): любой клик мышью (перемещение каретки, выделение, смена фокуса) сбрасывает накопленный буфер.
* Смена активного окна Windows также гарантированно очищает контекст.

### 4. Поддержка более 45 мировых языков
* В настройках доступны селекторы исходного языка («С какого») и целевого языка («На какой»).
* Поддерживается режим автоопределения (`auto`), а также языки Европы, СНГ, Азии и Ближнего Востока.
* Диспетчер перевода поддерживает локальные словари, морфологический стемминг русских окончаний и высокоскоростной движок с кэшированием в памяти (0 мс при повторных запросах).

### 5. Решение проблемы потери контекста (WSD — Word-Sense Disambiguation)
* Скользящий буфер контекста передает текущую фразу вместе с 1–3 предшествующими предложениями контекста.
* Сессионные терминологические якоря (Term Anchors): если в текущей сессии слово определено в определенном домене (например, *leaf* как лист растения), сессионный словарь блокирует значения из других доменов (*sheet of paper*).

### 6. Альтернативные сценарии ввода
* Quick Select (двойной `Ctrl + C`): при выделении текста и быстром двойном нажатии `Ctrl + C` всплывает компактный оверлей рядом с курсором мыши.
* In-place Replace (`Ctrl + Shift + T`): выделенный текст переводится и заменяется без открытия окна.
* Вызов/скрытие плавающего оверлея по `Ctrl + Space` или `Esc`.

## Горячие клавиши

| Сочетание клавиш | Действие |
| --- | --- |
| Alt + T | Включение / выключение прямого перевода при вводе |
| Ctrl + Space | Показать / скрыть оверлей HUD |
| 2x Ctrl + C | Быстрый перевод выделенного фрагмента у курсора |
| Ctrl + Shift + T | Заменить выделенный текст переводом на месте |
| Esc | Закрыть оверлей HUD |
| Ctrl + A, Ctrl + X, Ctrl + Z | Сброс буфера контекста фразы |

## Требования к системе

* Windows 10 / 11 (x64)
* Python 3.10 или новее
* Доступ в сеть для облачных провайдеров или локальный Ollama для полностью автономной работы

## Установка и запуск

1. Клонируйте репозиторий:
```bash
git clone https://github.com/3umukc/context-hud-translator.git
cd context-hud-translator
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Запустите приложение:
```bash
python main.py
```

Приложение свернется в системный трей Windows и сразу готово к работе. Для работы в играх (например, Dota 2, CS2) запускайте терминал от имени Администратора, а игру переключите в режим «В окне без рамки» (Borderless Window).

---

## Настройка провайдеров

В меню системного трея выберите **Настройки...**:
1. Выберите исходный и целевой языки перевода.
2. При необходимости введите ключи облачных сервисов:
   * Google Gemini API Key
   * Groq Cloud API Key
   * DeepL Free API Key
3. Выберите режим провайдера: `auto`, `groq`, `gemini`, `deepl` или `offline`.
4. Нажмите **Сохранить**. Конфигурация сохраняется в файле `~/.context_hud_translator/config.json` и применяется немедленно.
